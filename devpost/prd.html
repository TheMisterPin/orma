PRD · proof of concept

Orma

Landing and login, upload one photo, extract place and time, generate a caption you can edit, save, and browse by day or place—with tags and honest handling when metadata is missing.

Draft — review

Canonical plan: devpost/prd.md. This page is the review companion.

Scope said “upload a day, group moments, write a diary.” For this proof of concept we spelled out the first vertical: one image at a time, metadata on screen, AI caption, confirm, save, then day/place views and tags—people grouping waits.

Core journey

Step by step

Landing

Signed out

Explain Orma in plain language. One primary Log in button. No private diary content before auth.

  • Visitor sees explanation + Log in CTA.

Diary home

Signed in

List saved memories. Toggle grouping by day or place. Empty state: CTA to create from an image.

  • Zero memories → create CTA visible.
  • Day/place grouping shows correct sets.

Upload modal

One file

Preview image. Show timestamp and address from lat/long when EXIF allows. Then Generate memory.

  • Preview + extracted place/time visible before generate.

Generate & confirm

Review before save

AI returns a caption using the image and location context. User edits if needed, then confirms.

  • Caption appears after generate; editable before save.
  • Saved memory shows on home.

Evidence & tags

Trust the record

Each memory shows place, day, and caption. Tap day or place to see siblings. User can add tags.

  • Place, day, caption visible together.
  • Tags can be added and persist.

Missing metadata

Fail honestly

Error when required metadata is absent. Offer manual place and time, with shortcuts for current location and current time.

  • Clear error message; manual path reachable.

Look and feel

Paper-like surfaces, warm tones, dark green and matte brown, organic and matte—notebook meets nature. Trustworthy diary, not generic AI chrome.

Now vs deferred

Building now
  • Landing, login, personal diary home.
  • Single-image upload, metadata, AI caption, edit, save.
  • Browse by day and place; tags.
  • Missing-metadata error + manual fix shortcuts.
Deferred
  • Group by people (after first vertical).
  • Multi-photo “one day” import and automatic moment grouping.
  • Library import, calendar, large search — per scope.
